# Skarbnik – program dla skarbnika klasowego (Windows)

1. Wgraj całą zawartość tego folderu do repozytorium GitHub (z folderem `.github`).
2. Actions → "Build Windows EXE" → Run workflow.
3. Pobierz `Skarbnik.exe` z zakładki Releases i uruchom (Windows może zapytać o zgodę – "Więcej informacji → Uruchom mimo to").
4. Dane zapisują się same w `skarbnik_dane.json` obok programu (+ kopia `.bak`). Skopiuj ten plik jako backup.
5. Plik > "Wczytaj dane przykładowe" albo "Importuj z Excela" (Skarbnik_Klasowy.xlsx).
